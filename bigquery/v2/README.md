## BigQuery v2 (Experimental)

This module (`cloud.google.com/go/bigquery/v2`) is **experimental** and subject to change or removal without notice. Its root package provides no functionality.

For production workloads, use the generally available packages instead:

- [`cloud.google.com/go/bigquery`](https://pkg.go.dev/cloud.google.com/go/bigquery) for queries, jobs, datasets, tables, models, routines, and bulk loads/extracts.
- [`cloud.google.com/go/bigquery/storage/managedwriter`](https://pkg.go.dev/cloud.google.com/go/bigquery/storage/managedwriter) for high-throughput streaming ingestion using the BigQuery Storage Write API.
- [`cloud.google.com/go/bigquery/storage/apiv1`](https://pkg.go.dev/cloud.google.com/go/bigquery/storage/apiv1) for direct low-level access to the BigQuery Storage Read and Write gRPC APIs.
